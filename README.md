# HALLOWEEN TRIVIA GAME

It is a remake of project [faaezah/HalloweenTriviaGame](https://github.com/faaezah/HalloweenTriviaGame). It has 15 quetions with 5 easy, medium and hard. It has jumpscares also.

![screenshot](https://cdn.hackclub.com/01a1df4d-9b18-7336-9afd-8af8f7ff72a7/8a29fc5f-5823-46cd-840b-b510310b1e39.png)

## HOW TO PLAY

Run this command to clone the repo
```
git clone https://github.com/Yuser00123/HalloweenTriviaGame
```
Then open the index.html file. Make sure that you are connected to internet.

## FEATURES

- Has 15 questions
- Can generate certificate on quiz completion
- On every wrong answer you have choice to see jumpscare or quit the game
